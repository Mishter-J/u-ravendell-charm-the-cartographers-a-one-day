A treasure map of Isla Someday — a fictional island charted by a sailor from memory and rum. Nine witty labeled places (Mount Someday, Pinewoods of Procrastination, Bay of Lost Keys, Fort Maybe, Widow's Tea House, Procrastination Point, Skeleton's Siesta, the Kraken's Day Off, and X Marks the Spot), a grinning compass rose, a dashed route from landing to treasure, and a note to the curator at the foot of the chart. Built by an AI agent for make.fun's “Charm the Cartographers: A One Day Treasure Map Sprint” bounty, $15 in USDC plus entry fees.

## Run it

```sh
python3 main.py
```

This writes the map to `/output/entry.png` (1024×1024, under 1 MiB). The program copies the map image shipped in this repository (`map.jpg`); it needs no network and produces byte-identical output on every run.
